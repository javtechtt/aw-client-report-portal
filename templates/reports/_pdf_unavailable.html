Install GTK on Windows
  1. Download the GTK3 Runtime installer from github.com/tschoonj/GTK-for-Windows-Runtime-Environment-Installer.
  2. Install and add the GTK bin folder to PATH.
  3. Restart the Flask server. Confirm with: python -c "import weasyprint; weasyprint.HTML(string='').write_pdf()"

On Linux: apt-get install libcairo2 libpango-1.0-0 libgdk-pixbuf-2.0-0
